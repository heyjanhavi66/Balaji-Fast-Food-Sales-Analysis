# Balaji Fast Food Sales Analysis – EDA Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Balaji Fast Food sales data using Python to identify business trends, product performance and customer purchasing patterns.

## Business Objectives
- Analyse total sales and revenue.
- Identify top and low-performing products.
- Understand sales trends across different time slots.
- Analyse monthly revenue patterns.
- Compare payment methods.
- Evaluate weekday and weekend performance.
- Analyse staff performance.

## Dataset
- Total Records: 1,000
- Total Columns: 10
- Data Format: CSV

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning
- Checked missing values.
- Identified duplicate records.
- Handled missing payment values using Unknown.
- Converted date column into datetime.
- Verified transaction amounts.
- Created month, weekday and weekend columns.

## Exploratory Data Analysis
- Product revenue analysis
- Sales by time of day
- Monthly revenue trends
- Payment method analysis
- Weekday vs weekend sales
- Staff performance
- Product vs time-of-day heatmap

## Key Findings
- Total Revenue: ₹275,230
- Total Units Sold: 8,162
- Average Order Value: ₹275.23
- Top Revenue Product: Sandwich
- Highest Revenue Time Slot: Night
- Missing Payment Records: 107

## Business Recommendations
1. Prioritize high-revenue products.
2. Improve stock and staffing during peak sales hours.
3. Improve payment data collection.

## Conclusion
This project demonstrates how Python-based EDA can help businesses understand sales performance, identify trends and make data-driven decisions.
